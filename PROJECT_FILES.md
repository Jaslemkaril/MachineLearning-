# Project Files & Dependencies

This document lists all files created in the Electricity Consumption Prediction System and their dependencies.

---

## Python Scripts

### config.py
**Purpose**: Centralized constants, feature definitions, and mappings
**Dependencies**: None (Python standard library only)
**Used by**: `app.py`, `train_model.py`, `precompute_stats.py`, `generate_dataset.py`
**Output**: None

### generate_dataset.py
**Purpose**: Generates synthetic `smart_meter_data.csv` with 8,000 records over 8 months
**Dependencies**: 
- `config.py` (DORMS, APPLIANCE_INFO, FEATURE_COLS, etc.)
- `pandas`, `numpy`, `random`
**Output**: `smart_meter_data.csv`

### train_model.py
**Purpose**: Trains regression models (RF, LR) and classification models (RF, SVM, XGBoost)
**Dependencies**:
- `config.py` (FEATURE_COLS, APPLIANCE_COLS, etc.)
- `pandas`, `numpy`, `matplotlib`, `seaborn`
- `scikit-learn` (RandomForestRegressor, LinearRegression, RandomForestClassifier, SVC, metrics)
- `xgboost` (optional, for XGBClassifier)
- `joblib` (for saving models)
**Output**: 
- `electricity_model.pkl` (RF regressor)
- `electricity_model_lr.pkl` (LR baseline)
- `electricity_classifier.pkl` (best classifier)
- `actual_vs_predicted.png`
- `residual_plot.png`
- `confusion_matrices.png`

### precompute_stats.py
**Purpose**: Pre-computes model metrics and chart data for dashboard (cached for fast app startup)
**Dependencies**:
- `config.py` (FEATURE_COLS, DORM_MAP, SIZE_MAP, ANOMALY_THRESHOLD)
- `pandas`, `numpy`, `matplotlib`, `joblib`, `scikit-learn`
- `electricity_model.pkl`
- `electricity_model_lr.pkl`
- `electricity_classifier.pkl`
- `smart_meter_data.csv`
**Output**: `stats_cache.json`

### app.py
**Purpose**: Flask web application with prediction routes, dashboard, room management
**Dependencies**:
- `config.py` (all constants, feature lists)
- `pandas`, `numpy`, `joblib`
- `flask`
- `electricity_model.pkl`
- `electricity_classifier.pkl`
- `stats_cache.json`
- `room_config.json`
- `prediction_history.json`
**Output**: Web interface (serves `templates/index.html`)

---

## Data Files

### smart_meter_data.csv
**Purpose**: Training dataset with 8,000 records
**Generated by**: `generate_dataset.py`
**Used by**: `train_model.py`, `precompute_stats.py`
**Columns**: 22 features (Timestamp, Dorm_ID, Room_ID, Electricity_Consumed, Hour, Day, Month, IsWeekend, TimeOfDay, RoomSize, Num_Occupants, 9 appliance flags, 9 appliance wattages)

### room_config.json
**Purpose**: Room configurations (size, occupants) per dorm
**Generated by**: Initial JSON file (editable via web UI)
**Used by**: `app.py` (for room dropdowns, occupancy auto-fill)
**Structure**: 
```json
{
  "Dorm A": {"Room 1": {"size_m2": 20, "size_cat": "Medium", "occupants": 2}, ...},
  "Dorm B": {...},
  "Dorm C": {...}
}
```

### prediction_history.json
**Purpose**: Stores recent prediction history (max 50 entries)
**Generated by**: `app.py` (auto-managed)
**Used by**: `app.py` (for Avg_Past_Consumption derivation)
**Structure**: List of prediction entries with dorm, room, time, result, status, kwh, cost, etc.

### stats_cache.json
**Purpose**: Cached model metrics and chart data for dashboard
**Generated by**: `precompute_stats.py`
**Used by**: `app.py` (loaded at startup)
**Contents**: MAE, RMSE, R², CV R², LR metrics, classification metrics, feature importances, top rooms, monthly/hourly/dorm chart data, dataset info, base64-encoded actual vs predicted chart

## Model Files (.pkl)

### electricity_model.pkl
**Purpose**: Trained Random Forest Regressor (primary model for consumption prediction)
**Generated by**: `train_model.py`
**Used by**: `precompute_stats.py`, `app.py`
**Model**: `sklearn.ensemble.RandomForestRegressor`

### electricity_model_lr.pkl
**Purpose**: Trained Linear Regression (baseline for comparison)
**Generated by**: `train_model.py`
**Used by**: `precompute_stats.py`
**Model**: `sklearn.linear_model.LinearRegression`

### electricity_classifier.pkl
**Purpose**: Best classifier for high consumption detection (RF, SVM, or XGBoost)
**Generated by**: `train_model.py` (selects best by accuracy)
**Used by**: `precompute_stats.py`, `app.py`
**Model**: Usually `sklearn.ensemble.RandomForestClassifier`
