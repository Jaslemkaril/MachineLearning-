About This Project
Dataset
5,000 smart meter readings at 30-minute intervals across 3 dorms and 24 rooms. Features include temperature, humidity, wind speed, room details, occupancy, and 9 appliances with real brand/wattage data, normalized to a 0–1 scale.
Model
{{ stats.model_type }} trained on {{ stats.importances|length }} features including real appliance loads. Time-based 70/30 train-test split preserves temporal integrity.
Feature Engineering
IsWeekend, Season (0–3), and TimeOfDay are auto-derived from time inputs. Appliance_kWh_Active is computed from rated wattage × active flags × 0.5 h. Room size and dorm are label-encoded.
Appliance Reference
Users can input custom wattage for their specific appliances. Default values: Fan 35W · AC 1200W · Laptop 65W · Fridge 120W · TV 40W · Charger 20W · Kettle 1500W · Rice Cooker 400W · Lamp 9W
